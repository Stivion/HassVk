# Зачем
Для управления умным домом откуда угодно. Я не хочу чтобы мой Home Assistant был доступен в Интернете, я не хочу настраивать на роутере VPN для доступа в домашнюю сеть. Использовать бота ВК для меня самый простой способ. Плюсом ВКонтакте находится в белых списках.

# Как работает
Я открываю в ВК чат с ботом и отправляю ему любую команду. Бот получает ее и публикует в Home Assistant соответствующее событие. Дальше срабатывает автоматизация на это событие.

# Что нужно для использования
Нужно создать сообщество в ВК, можно закрытое. Нужно создать Access Token с правами `community management, community messages`. Нужно включить `Long Poll API` и включить `Message received` события. Нужно получить числовой идентификатор созданного сообщества, он есть в URL.
